The first version of Sinan draws everything Kite can give a docs site today.

## What is in it

- A home page with a headline, buttons, feature cards and the latest news.
- Docs in a tree of groups and pages, set in the studio, with previous and next links in reading order.
- A table of contents that marks the section being read.
- Light and dark, a drawer on a narrow screen, and copy buttons on code.
- A search by title across the docs tree.

## What comes next

Kite does not yet write a search index, keep an order among its pages, or know where a page's file lives. As it learns each, Sinan will search the text of the pages, draw the tree from the pages themselves, and link to where a page can be edited.
