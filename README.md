# Kite docs theme

A documentation theme for [Kite](https://github.com/kite-plus/kite): a home
page, documents in a tree with their own order, news, and search, in light and
dark. It is the theme [www.kite.plus](https://www.kite.plus) is to be built
with, and the second theme written against Kite's theme contract, which
freezes once a theme this different from the default one has been written.

Nothing is built yet. The plan, with what Kite has to add for it, is in
[docs/design/README.md](docs/design/README.md).
